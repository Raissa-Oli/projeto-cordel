# 📜 Cordel Moderno

Projeto desenvolvido durante os estudos de **HTML5 e CSS3**, com o objetivo de criar uma página web para apresentar o poema **"Cordel Moderno"**, de Milton Duarte.

O projeto utiliza diferentes seções, imagens de fundo e efeitos visuais para criar uma experiência de leitura mais interessante e moderna.

## 🌐 Projeto online

Você pode acessar o projeto publicado pelo GitHub Pages:

**[Acessar o Cordel Moderno](https://raissa-oli.github.io/projeto-cordel/)**

## 📖 Sobre o projeto

O site apresenta o poema "Cordel Moderno", que aborda de forma descontraída as mudanças na comunicação causadas pelo avanço da tecnologia.

Durante a leitura, o usuário encontra trechos do poema intercalados com imagens de fundo, criando um efeito visual semelhante ao **parallax**.

## 🎨 Principais recursos

* Estrutura semântica utilizando HTML5
* Cabeçalho com título e autoria do poema
* Seções para organização dos versos
* Imagens de fundo utilizando CSS
* Efeito de paralaxe nas seções com imagens
* Links externos para referências
* Layout responsivo para diferentes tamanhos de tela
* Publicação utilizando GitHub Pages

## 📚 O que foi praticado

Com este projeto, foi possível praticar:

* Estrutura básica de um documento HTML
* Utilização de `header`, `section` e `footer`
* Inserção de links com a tag `<a>`
* Utilização de classes e IDs no HTML
* Organização do conteúdo em diferentes seções
* Estilização de páginas com CSS
* Utilização de imagens como plano de fundo
* Criação de efeitos visuais com CSS
* Publicação de um site utilizando GitHub Pages
